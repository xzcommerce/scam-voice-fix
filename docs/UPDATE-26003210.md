# Update audit: 0.1.73 / Steam build 26003210

Inspected 17 October 2026. [Official update notes](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1846651706683757).

## What changed officially

- Qwen first-audio deadline increased from five to seven seconds.
- Qwen speech chunk buffering, playback scheduling and unload handling changed.
- The Qwen worker client constructor is unchanged from build 25996926: it still inherits the parent process environment without removing the NVIDIA cache overrides.
- All 25 installed Qwen runtime files match the previous runtime manifest by SHA-256.

The update contains related speech improvements, but does not implement this worker cache workaround. This static comparison does not mean that every updated PC will still lag: cache state and hardware affect startup time.

The patch is rebuilt from the new original, not from the old patched game file. A comparison of all method bodies found only four changed worker-client methods (constructor, Load, Synthesize, stderr handler) and one added diagnostic logger. Other method bodies, including the official new buffering and seven-second deadline, are unchanged.

Backups use a separate `26003210-...` directory under `%LOCALAPPDATA%/ScamVoiceFix`; older build backups are retained. Undo restores this build's original DLL and the preferences recorded when this installer ran.

## Validation

- Exact source rebuild and binary-delta reconstruction passed.
- All eight isolated installer test groups passed: install/repeat, undo, unknown DLL rejection, truncated delta rejection, failure rollback and Unicode paths.
- English and Russian GUI compilation, layout bounds, read-only compatibility checks and localized error recovery passed through direct control rendering/process-controller tests.
- Installed game, official runtime, models and reference voice checks passed.
- Official-worker preparation and fresh-worker performance gate passed before installing on the test PC.

The test PC remains RTX 3060 12 GB / Ryzen 7 PRO 3700 / 32 GB RAM. Other PCs, multiplayer and cold-cache behavior on new hardware remain unverified.
